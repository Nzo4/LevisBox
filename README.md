# LevisBox

Лёгкое расширение для управления HTTP-заголовками в браузере **Levitas**. Профили для разных сайтов, заголовки запросов и ответов, пауза и резервные копии в JSON. Без фоновой страницы, дополнительных процессов и телеметрии.

## Браузеры и системы

| Браузер | Система | Статус текущего релиза |
| --- | --- | --- |
| **Levitas с поддержкой заголовков** | **macOS 15.4+, Apple Silicon M1 и новее** | Поддерживается; проверено на macOS 26.3.1 |
| Levitas на Intel Mac | macOS | Не проверено; текущая сборка браузера рассчитана на arm64 |
| Safari | macOS, iOS, iPadOS | Не поддерживается этим ZIP: нужна отдельная интеграция и упаковка для Safari |
| Google Chrome, Chromium, Microsoft Edge, Brave, Opera | Windows, macOS, Linux | Не поддерживаются этим релизом: отдельной сборки без host Levitas пока нет |
| Mozilla Firefox, Zen | Windows, macOS, Linux | Не поддерживаются этим релизом: адаптация не выполнена |
| Мобильные браузеры | Android, iOS, iPadOS | Не поддерживаются |

Это версия **для Levitas**, а не универсальный пакет для всех браузеров WebExtensions. `engine.js` обращается к встроенному native messaging host `dev.levitas.browser.headers`. Установка ZIP в другой браузер сама по себе этот host не создаёт. [Chrome требует регистрации native host](https://developer.chrome.com/docs/extensions/develop/concepts/native-messaging), а [Safari использует собственную упаковку и интеграцию](https://developer.apple.com/documentation/safariservices/safari-web-extensions).

## Возможности

- Создание, копирование и удаление профилей; одновременно применяется один профиль.
- Заголовки запросов и ответов: «Задать», «Добавить», «Удалить».
- Включение отдельных правил и общая пауза.
- Фильтры по домену, поддоменам и пути URL.
- Доступ к сайтам запрашивается при применении профиля.
- Импорт и экспорт JSON LevisBox; импорт старых файлов Levitas Headers и ModBox v1.
- Светлая и тёмная темы по настройкам системы.

## Установка

Нужен Levitas с интеграцией заголовков: основной документ GET/HEAD, Fetch/XHR и проверка разрешений при редиректах. Одной поддержки WebExtensions в браузере недостаточно.

1. Скачайте готовый [LevisBox 1.0.0 ZIP](LevisBox-1.0.0.zip?raw=true).
2. В Levitas нажмите кнопку расширений → «Управление расширениями…» → «Установить из файла…».
3. Выберите скачанный ZIP и подтвердите указанные разрешения.
4. Откройте **LevisBox**, добавьте профиль и правила, нажмите «Применить» и разрешите доступ к указанному сайту.
5. Перезагрузите страницу через `Cmd+R`.

Исходный каталог репозитория с `manifest.json` тоже можно установить напрямую. В магазины Chrome, Firefox и App Store этот релиз не опубликован.

Если раньше использовалось **Levitas Headers**, сначала экспортируйте его настройки, установите LevisBox, импортируйте JSON и выключите старое расширение. Названия отличаются, поэтому менеджер Levitas рассматривает их как два отдельных расширения. Автоматический перенос между ними не выполняется.

## Фильтры

| Пример | Какие запросы совпадают |
| --- | --- |
| `example.com` | Только этот домен, HTTP и HTTPS |
| `*.example.com` | Этот домен и его поддомены |
| `https://api.example.com/v1/*` | HTTPS, указанный хост и путь `/v1/` |
| `*` | Разрешённые HTTP(S) сайты; потребует общего доступа |

Поддерживаются до 20 профилей и 100 строк в каждом. Для каждого имени и направления допускается одно активное правило. Имена сравниваются без учёта регистра; управляющие символы и переносы строк в значениях отклоняются.

## JSON

**«Экспорт JSON»** сохраняет все профили, значения, фильтры и флажки правил. Файл имеет формат `levisbox`, версию данных `1`; в экспорт также входят несохранённые изменения редактора. В popup экспорт открывает редактор во вкладке и использует обычный диалог загрузки Levitas.

**«Импорт JSON»** принимает:

- LevisBox: `format: "levisbox"`, версия 1.
- Levitas Headers: `format: "levitas-headers"`, версия 1.
- ModBox: `name: "modbox"`, версия 1.

Импорт добавляет профили и сохраняет их **на паузе**, не выдавая новых разрешений. Нажмите «Продолжить», чтобы запросить доступ и включить правила. Максимальный размер файла — 2 МБ.

В ModBox сохраняются значения, направления и флажки правил. Домен включает поддомены; список доменов превращается в отдельные профили. Индивидуальные фильтры строк, блокировки и перенаправления пока не поддерживаются: такой импорт целиком отклоняется, чтобы не потерять ограничения.

Примеры и тесты содержат только вымышленные значения. Экспорт ваших настроек содержит введённые значения заголовков и предназначен для локальной резервной копии.

## Как меняются заголовки и какие есть ограничения

Стандартные заголовки с операциями «Задать» и «Удалить» используют WebKit `declarativeNetRequest`. WebKit [пока отклоняет произвольные имена заголовков](https://bugs.webkit.org/show_bug.cgi?id=290922), поэтому нестандартные имена и операция «Добавить» используют интеграцию Levitas:

- **Fetch / XMLHttpRequest:** изменение исходящих заголовков; изменение представления заголовков ответа для JavaScript.
- **Основной документ GET/HEAD:** заголовки добавляются при вводе URL, обычных ссылках, восстановлении вкладки и перезагрузке. Одноразовый URLSession проверяет каждый редирект, использует cookies браузера и передаёт ответ WebKit через публичный `loadSimulatedRequest` с HTTP-статусом и CSP. Размер документа ограничен 16 МБ.

Нестандартные заголовки этим механизмом не добавляются к формам POST, iframe-навигациям, изображениям, скриптам, стилям, WebSocket и запросам Web Worker / Service Worker. Fetch/XHR требуют доступа также к странице, выполняющей запрос. Стандартные DNR-правила не обрабатывают отдельный запрос URLSession основного документа; это ограничение профилей, совмещающих стандартные и нестандартные заголовки.

LevisBox не обходит HTTP, TLS, CORS или CSP и не обещает полной совместимости с ModHeader. Подробности интеграции: [native-host.md](native-host.md).

## Разработка

Нужен Node.js 20+ для тестов и Python 3.9+ для упаковки. Зависимостей npm нет.

```sh
npm test
python3 package.py
```

Архив создаётся из явного списка файлов. В него не входят тесты, документация, настройки пользователей или данные браузера. Автотесты проверяют фильтры URL, разделение DNR/native, откат при ошибках, паузу, сохранение профилей и импорт/экспорт JSON.

Сетевая интеграция проверена в Levitas: первый запрос документа, переходы по ссылкам, Fetch/XHR, замена/удаление/добавление заголовков, пауза, редирект на другой домен и сохранение настроек после перезапуска. Другие браузеры и системы из таблицы не тестировались.
